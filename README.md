A desktop application to easily download and save all your children's photos and activities from Educartable to your computer.

## Features

- **Photo Synchronization**: Download all photos and documents shared by teachers on Educartable with a single click
- **Automatic Organization**: Files are sorted into folders by date and activity name
- **Automatic Updates**: The application notifies you when a new version is available and installs it automatically

## Installation

Download the latest version for your operating system from the [Releases page](https://github.com/bombfork/educartable-sync/releases/latest).

### Windows

1. Download the file ending in `.exe` (e.g., `educartable-sync_1.0.0_x64-setup.exe`)
2. Run the installer
3. Follow the installation wizard
4. Launch Educartable Sync from the Start menu

### macOS

1. Download the file ending in `.dmg` (e.g., `educartable-sync_1.0.0_x64.dmg`)
2. Open the downloaded file
3. Drag the Educartable Sync icon to the Applications folder
4. Launch the application from Applications

> **Note**: On first launch, you may need to right-click the app and select "Open" to bypass Gatekeeper security.

### Linux

1. Download the file ending in `.AppImage` (e.g., `educartable-sync_1.0.0_amd64.AppImage`)
2. Make the file executable: right-click > Properties > Permissions > Allow executing as program
3. Double-click to launch

## How to Use

1. **Connect**: Click "Se connecter" and log in with your Educartable credentials
2. **Choose a folder**: Select where you want to save the photos on your computer
3. **Synchronize**: Click "Synchroniser" to download all activities and photos

The application will remember your settings and only download new files on subsequent syncs.
