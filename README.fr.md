Une application de bureau pour télécharger et sauvegarder facilement toutes les photos et activités de vos enfants depuis Educartable sur votre ordinateur.

## Fonctionnalités

- **Synchronisation des photos** : Téléchargez toutes les photos et documents partagés par les enseignants sur Educartable en un seul clic
- **Organisation automatique** : Les fichiers sont triés dans des dossiers par date et nom d'activité
- **Mises à jour automatiques** : L'application vous prévient quand une nouvelle version est disponible et l'installe automatiquement

## Installation

Téléchargez la dernière version pour votre système d'exploitation depuis la [page des Releases](https://github.com/bombfork/educartable-sync/releases/latest).

### Windows

1. Téléchargez le fichier se terminant par `.exe` (ex: `educartable-sync_1.0.0_x64-setup.exe`)
2. Lancez l'installateur
3. Suivez l'assistant d'installation
4. Lancez Educartable Sync depuis le menu Démarrer

### macOS

1. Téléchargez le fichier se terminant par `.dmg` (ex: `educartable-sync_1.0.0_x64.dmg`)
2. Ouvrez le fichier téléchargé
3. Glissez l'icône Educartable Sync dans le dossier Applications
4. Lancez l'application depuis Applications

> **Note** : Au premier lancement, vous devrez peut-être faire un clic droit sur l'application et sélectionner "Ouvrir" pour contourner la sécurité Gatekeeper.

### Linux

1. Téléchargez le fichier se terminant par `.AppImage` (ex: `educartable-sync_1.0.0_amd64.AppImage`)
2. Rendez le fichier exécutable : clic droit > Propriétés > Permissions > Autoriser l'exécution
3. Double-cliquez pour lancer

## Comment utiliser

1. **Se connecter** : Cliquez sur "Se connecter" et identifiez-vous avec vos identifiants Educartable
2. **Choisir un dossier** : Sélectionnez où vous voulez sauvegarder les photos sur votre ordinateur
3. **Synchroniser** : Cliquez sur "Synchroniser" pour télécharger toutes les activités et photos

L'application mémorise vos paramètres et ne télécharge que les nouveaux fichiers lors des synchronisations suivantes.
